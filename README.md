# Tech Job Market Analytics & Salary Prediction

A production-grade Data Science & Machine Learning capstone project providing tech compensation analytics, salary regression, and salary band classification.

> ⚠️ **Important Notice: Synthetic Dataset**  
> The underlying dataset (`data/jobs.csv`, 90,000 records, 35 columns) exhibits properties characteristic of synthetic data generation. All findings, predictive models, and dashboard estimates illustrate machine learning principles and must not be used as real compensation benchmarks.

---

## 🛠️ Algorithms & Concepts Used

### Allowed Algorithms
- **Linear / Ridge / Lasso Regression**: Linear baseline with L2 and L1 regularization to examine feature shrinkage and sparsity.
- **Stochastic Gradient Descent (SGD)**: Iterative optimization using `SGDRegressor` with squared error loss to demonstrate epoch convergence.
- **Decision Trees**: Partition-based regression (`DecisionTreeRegressor`) and classification (`DecisionTreeClassifier`).
- **Random Forest**: Ensemble bagging (`RandomForestRegressor` and `RandomForestClassifier`) for non-linear modeling and feature importance.
- **K-Nearest Neighbors (KNN)**: Non-parametric distance-based classification (`KNeighborsClassifier`).
- **Naive Bayes**: Probabilistic classification with `GaussianNB`.

### Core Concepts & Preprocessing
- **Leakage Removal**: Explicit exclusion of `bonus_usd`, `signing_bonus_usd`, `stock_options_usd`, `total_compensation_usd`, `salary_percentile`, and post-hire survey metrics.
- **Feature Selection**: CORE (10 candidate-input features) vs EXTENDED (20 features including macroeconomic indicators).
- **Transformations**: `OneHotEncoder(handle_unknown='ignore')` for categorical attributes, `StandardScaler()` for numerical features, and `log1p` / `expm1` transformations on salary.
- **Evaluation Metrics**:
  - Regression: Train $R^2$, Test $R^2$, Generalization Gap ($R^2_{train} - R^2_{test}$), Mean Absolute Error (MAE in dollars), Root Mean Squared Error (RMSE in dollars).
  - Classification: Accuracy, Precision, Recall, F1-Score (weighted), and Confusion Matrix.
- **Dimensionality Reduction**: Principal Component Analysis (PCA) on macroeconomic indicators.
- **Bias-Variance Diagnostics**: Systematic manual parameter sweeps plotting train vs test $R^2$ across depths and regularization strengths.

## 📌 Key Decisions Made

1. **Leakage Elimination**: All post-hire outcomes, compensation components (`bonus_usd`, `signing_bonus_usd`, etc.), and derived percentiles were strictly removed before splitting.
2. **CORE Feature Deployment**: EXTENDED macroeconomic variables (such as `economic_index` and `cost_of_living_index`) provided $0.00$ lift in test $R^2$. Consequently, production pipelines use only the 10 CORE attributes, preventing users from needing external macroeconomic statistics.
3. **Log-Transform Target**: Salary distributions are right-skewed; modeling $\log(1 + \text{salary})$ stabilizes variance and aligns with proportional compensation scaling.
4. **Transparent Hyperparameter Tuning**: Manual iteration loops over regularization penalties ($\alpha$) and tree depths explicitly demonstrate underfitting vs. overfitting without opaque cross-validation grids.
5. **Prediction Range Formulation**: In compliance with simplified requirements, uncertainty is communicated via the empirical Test MAE range: $\text{Predicted} \pm \text{Test MAE}$.
